# Changelog

## [1.0.0] — 2026-10-04

Первый релиз.

### Возможности

- **Маршруты вебхуков.** У каждого маршрута свой секретный адрес для Grafana, свой чат и тема форума. Можно включать и выключать маршрут и менять его адрес.
- **Шаблоны** на Jinja2 (в песочнице) с Telegram HTML и живым предпросмотром «как в Telegram». Предпросмотр строится на примере или на последнем реальном алерте.
- **Два способа доставки:** Bot API через SOCKS5/HTTP прокси или MTProto через MTProxy (Telethon).
- **Постоянная очередь** с повторами: пауза растёт от 15 с до 30 мин с учётом `retry_after`. Если Telegram отклонил HTML, сообщение переотправляется простым текстом.
- **Журнал доставки** с ошибками и кнопкой «отправить сейчас». На главной странице есть статистика за 24 ч.
- Отдельное сообщение на каждый алерт и тихие уведомления «решено».
- Поиск `chat_id` по последним сообщениям боту.
- Вход по паролю, маскировка секретов в интерфейсе. После смены пароля остальные сессии завершаются.
- Светлая и тёмная темы, мобильная вёрстка.
- **Установщик одной командой** для установки и обновления через Docker Compose. Работает на amd64 и arm64, в том числе на Raspberry Pi.

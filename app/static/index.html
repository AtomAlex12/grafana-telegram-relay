Маршруты

Каждый маршрут — свой адрес вебхука для Grafana и свой чат в Telegram.

Как подключить Grafana
  1. Grafana → Alerting → Contact points → + Add contact point.
  2. Integration: Webhook, URL — адрес вебхука из карточки маршрута (кнопка «копировать»).
  3. HTTP Method: POST. Остальное можно не трогать. Нажмите Test — сообщение придёт в чат.
  4. В Notification policies назначьте этот contact point нужным алертам.

Если Grafana работает в другой сети (например, через WireGuard/Tailscale), укажите во вкладке «Подключение» внешний адрес релея — он подставится в ссылки вебхуков.

Журнал отправок

Шаблон Jinja2 + Telegram HTML
Подсказка по шаблонам

Переменные: alerts (список), status, firing, resolved, commonLabels, commonAnnotations, externalURL, title, message, payload (весь JSON), route.

У алерта: a.status, a.labels.*, a.annotations.*, a['values'], a.valueString, a.startsAt, a.endsAt, a.panelURL, a.dashboardURL, a.generatorURL, a.silenceURL.

Фильтры: {{ a.startsAt | dt }}, {{ a.startsAt | dt('%H:%M') }}, {{ a | duration }}.

Теги Telegram: <b> <i> <u> <s> <code> <pre> <a href> <blockquote> <tg-spoiler>. Значения экранируются автоматически.
